# Red Moon Classic+

سيرفر Conquer Online مبني على FoxConquer5517 مع عميل 5517.

**الحالة الحالية — 2026-10-30:** المالك أكد `SETUP_OK` ثم `SERVERS_READY`، وبعد تثبيت اللودر أرسل صورًا من داخل اللعبة. الدخول الفعلي الأول تم على جهازه؛ هذا لا يعني أن كل أنظمة اللعب مكتملة أو أن السيرفر معتمد للإطلاق العام.

## افتح السورس هنا

**[src/RedMoon.sln](src/RedMoon.sln)** — حل منظم للمشاريع، أو دبل كليك على **`Open-RedMoon-Source.cmd`** من مجلد السورس في Windows.

- **Game Server:** [src/FoxConquer5517/MsgServer](src/FoxConquer5517/MsgServer)، البداية `Program.cs`.
- **Account/Login Server:** [src/FoxConquer5517/LoginServer](src/FoxConquer5517/LoginServer)، البداية `Program.cs`.
- **الداتابيز بالكود:** [src/FoxConquer5517/DB](src/FoxConquer5517/DB).
- **الكود المشترك:** [src/FoxConquer5517/ServerCore](src/FoxConquer5517/ServerCore).
- **أداة الإعداد المساعدة:** [src/RedMoon.Admin](src/RedMoon.Admin).

**[خريطة السورس والتشغيل والتحديث](docs/SOURCE-MAP.md)** تشرح التقسيم كاملًا. التنظيم الجديد للعرض داخل Visual Studio والتنقل بين المشاريع؛ لم تُنقل ملفات C# ولم تتغير namespaces أو أسماء ملفات التشغيل أو المسارات القائمة.

## تشغيل النسخة الموجودة عندك

**`Start-RedMoon.cmd` يشغّل السيرفرين الحقيقيين، وليس محاكاة أو وضع اختبار.** ملفات التشغيل في الحزمة هي `server/LoginServer.exe` و`server/MsgServer.exe`. السكربت يجهز البيئة والأسرار اللازمة قبل تشغيلهما في الخلفية.

- تشغيل: `Start-RedMoon.cmd` مرة واحدة، مع MySQL وHamachi شغالين.
- إيقاف منظم: `Stop-RedMoon.cmd` قبل غلق MySQL.
- السجلات: `.local/logs`؛ شارك الخطأ المطلوب فقط بعد إخفاء الأسرار.
- لا إعادة Setup أو استيراد SQL بعد نجاح التثبيت، ولا فتح EXEs مباشرة أو بناء فوق التثبيت الحي.

تعديل المصدر لا يبدّل ملفات التشغيل تلقائيًا. عند تحديث كود لاحقًا نحدد التجميع والنشر الآمن بشكل منفصل، مع الحفاظ على الداتا والإعدادات.
