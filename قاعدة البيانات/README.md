# قاعدة البيانات الرسمية النظيفة — سيرفر MoonQueen (`V6192` — المطور `ahmedzahran`)

هذا الفولدر يحتوي على حزمة قواعد البيانات الرسمية الكاملة والنظيفة 100% والجاهزة للتشغيل الفوري أوفلاين على **MariaDB `10.4.32` / XAMPP Control Panel `v3.3.0`** و**HeidiSQL `12.2`** بدون الحاجة لأي تحميل خارجي أو فك ضغط.

---

## 1. محتويات الفولدر

1. **`1-moonqueen_account.sql`** — قاعدة بيانات الحسابات النظيفة (**`moonqueen_account`**):
   - تنشئ قاعدة `moonqueen_account` تلقائيًا بترميز `utf8mb4_general_ci` بدون المساس بأي قواعد بيانات قديمة على جهازك (`redmoon_account` أو `redmoon_game`).
   - تضم جداول `conquer_account`، و`conquer_account_authority` (مُغذّى بجميع رتب الصلاحيات من `1 = Player` حتى `7 = GM` و`8 = PM` و`10 = Owner` لضمان عمل حسابات الإدارة بسلاسة مع قيد الـ Foreign Key)، و`conquer_account_vip`، و`realm`، و`realms_status`.
   - خالية تمامًا من أي حسابات قديمة أو كلمات مرور أو مفاتيح سرية، وتبدأ العدادات التلقائية من `1`.

2. **`2-moonqueen_game.sql`** — قاعدة بيانات عالم اللعبة الرسمية النقية (**`moonqueen_game`** — `Pure Official V6192 1.0x`):
   - تنشئ قاعدة `moonqueen_game` تلقائيًا وتضم **`302` جدولًا** و**`8` إجراءات مخزنة (`Stored Procedures`)** متوافقة 100% مع جميع مشاريع السورس (`MoonQueen.Game`، `MoonQueen.Ai`) ومع `موقع السيرفر/` و`لوحة تحكم السيرفر/`.
   - تحتوي بالكامل على بيانات عالم كونكر الرسمية النقية لإصدار **`V6192` (`1.0x`)** في **`65` جدولًا ثابتًا**: الخرائط والبوابات (`cq_map`, `cq_portal`, `cq_passway`, `cq_region`)، والوحوش ومولدات الرسبون ومهارات الزعماء (`cq_monstertype`, `cq_generator`, `cq_monster_type_magic`)، والـ NPCs والمتاجر والـ Mall (`cq_npc`, `cq_dynanpc`, `cq_goods`)، والعتاد والبلص والأسعار (`cq_itemtype`, `cq_itemaddition`)، والمهام والأحداث واليانصيب وأسئلة المسابقة (`cq_action`, `cq_task`, `cq_lottery`, `cq_quiz`)، وجداول الخبرة والريبيرث والأرينا والجيانج هو والتوتيم (`cq_levexp`, `cq_rebirth`, `cq_point_allot`, `cq_arenic_bonus`, `cq_arenic_honor`, `cq_jianghu_*`, `cq_ast_prof_*`, `cq_fate_*`).
   - تشمل الجداول والأعمدة الناقصة في الدامب الخام لإصدار `V6192` (`cq_instance_enter_condition`، و`cq_item_owner_history`، وأعمدة `cq_card` الكاملة، وحماية عدم القيم الفارغة `NOT NULL` في `cq_quiz` و`cq_tutor`).
   - مُطهّرة بالكامل من أي شخصيات أو أدوات أو جيلدات أو سجلات تجارة قديمة، مع الحفاظ على بداية عداد اللاعبين الرسمي عند `AUTO_INCREMENT = 1000001` (`PLAYER_ID_FIRST`) وعداد الخرائط الديناميكية عند `1000001` (`DYNAMAP_FIRST`)، وتصفير ملكية عمود وبوابات حرب الجيلد (`GuildWarPole 810` والبوابتين اليمنى واليسرى بكامل نقاط الحياة `10,000,000` / `20,000,000`) ورسالة الترحيب الرسمية باسم **`MoonQueen`** والمطور **`ahmedzahran`**.

---

## 2. طريقة التثبيت بضغطة واحدة (مُوصى بها — تعمل أوفلاين بدون إنترنت)

1. افتح **XAMPP Control Panel** واضغط **Start** أمام **MySQL**.
2. افتح فولدر **`تشغيل السيرفر`** في جذر المشروع وشغّل الملف:
   - **`7-Install-Clean-Database.bat`**
3. الأداة ستكتشف `mysql.exe` تلقائيًا، وتتأكد من عدم المساس بـ `redmoon_account` و`redmoon_game`، وتستورد `1-moonqueen_account.sql` ثم `2-moonqueen_game.sql` في ثوانٍ، وتتيح لك في نفس الخطوة تجهيز سطر ربط عالم **`MoonQueen`** وحساب الأدمن **`[PM]`** محليًا بأمان دون حفظ أي كلمة مرور داخل ملفات المستودع.

---

## 3. طريقة الاستيراد اليدوي عبر HeidiSQL (اختيارية)

1. افتح **HeidiSQL** واتصل بخادم `127.0.0.1` (بورت `3306`، مستخدم `root`).
2. من قائمة **File -> Run SQL file** اختر الملف الأول **`قاعدة البيانات\1-moonqueen_account.sql`** بترميز `UTF-8` وانتظر اكتماله في ثانية واحدة.
3. من قائمة **File -> Run SQL file** اختر الملف الثاني **`قاعدة البيانات\2-moonqueen_game.sql`** بترميز `UTF-8` وانتظر اكتمال استيراد الجداول الـ `302`.
4. شغّل **`تشغيل السيرفر\6-Generate-Realm-Admin-SQL.bat`** لتوليد ونسخ استعلام تسجيل سطر الـ `realm` وحسابك الـ `PM` ولصقه في HeidiSQL وتنفيذه بـ **F9**.
