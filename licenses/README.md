# Licensing and provenance

The maintained RedMoon source is derived from FoxConquer5517 at commit
`70f3560465ba73cef0250109af7cf167b508516f`.

- `FoxConquer5517-MIT.txt` is the upstream LICENSE, preserved byte-for-byte.
- Original authorship/copyright headers remain in the source. Renaming projects,
  assemblies and namespaces is not a claim of new authorship of that code.
- Embedded IniParser and CO2 compatibility definitions retain their source identity
  and notices; third-party package names are not rebranded.
- The Windows package additionally includes `third-party-packages.json` and
  `third-party-licenses/` collected from the restored package metadata.
- The game client and loader are not redistributed. Server runtime data provenance
  is recorded separately in the generated `data-provenance.json`; the source MIT
  license is not a blanket license claim for every game asset.

The original source and historical audit remain in the private Git repository,
not as a second competing editable source tree in the runnable Windows bundle.
