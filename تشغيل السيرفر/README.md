# تشغيل وتجهيز سيرفر MoonQueen (V6192 Pure 1.0x)
**المطور الرسمي:** `ahmedzahran` (`احمد زهران`)

تم توحيد وتبسيط كل أدوات التجهيز والتشغيل في **ملفين اثنين فقط** لتسهيل الإدارة بالكامل بدون أي تشتيت:

---

## 1) `1-Setup-MoonQueen.bat` — اسكريبت التجهيز الموحد الشامل (ينفّذ كل الأوامر بالترتيب ورا بعض)
شغّله عند التجهيز لأول مرة، أو في أي وقت تحب تبدّل فيه بين **الأوفلاين بدون إنترنت (`127.0.0.1`)** و**الهماشي (`25.21.212.130`)**، أو تركّب شارة `[PM]` لشخصيتك:

1. **`[1/6]` وضع الشبكة وفحص البيئة:** تختار أوفلاين (`127.0.0.1`) أو هماشي (`25.21.212.130`) وتحدد فولدر كلينت `6192` (بيتحفظ تلقائيًا عشان متكتبوش تاني).
2. **`[2/6]` مزامنة السيرفر والكلينت واللودر أوتوماتيك:**
   - ينسخ سكربتات `RequiredAssetsForRun\lua` (`31` اسكريبت) إلى `src\Bin\net7.0\lua`.
   - ينسخ فولدري `ini` و`map` من الكلينت إلى مسار السيرفر أوتوماتيك لو لسه مش منسوخين.
   - ينسخ أحدث نسخة مبنية من `MoonQueen.exe` و`ConquerCipherHook.dll` إلى الكلينت (لو اتعملهم Build).
   - يضبط `LoginHost` و`GameHost` في **`config.json`** داخل الكلينت (`Servers` و`DefaultServer`) على الآي بي المختار ويمسح أي `config.json.lock` قديم.
3. **`[3/6]` توليد ملفات الكونفيج المحلية الثلاثة (`*.Config.local.json`) تلقائيًا:**
   - يولّد مفاتيح `SharedKey` (`32` حرفًا) و`SharedIV` (`16` حرفًا) وباسوردات الربط الداخلي (`Realm` على بورت `9865` و`Ai` على بورت `9866`) أوتوماتيك بدون أي تعديل يدوي.
4. **`[4/6]` تثبيت أو مراجعة قاعدتَي البيانات النظيفتين (`moonqueen_account` + `moonqueen_game`):**
   - لو أول مرة، يستورد `1-moonqueen_account.sql` + `2-moonqueen_game.sql` (`302` جدول + `10` إجراءات مخزنة) فورًا بدون لمس قواعد `redmoon_*` القديمة.
   - لو متثبتين بالفعل، يحمي حساباتك وشخصياتك الحالية ويتابع فورًا.
5. **`[5/6]` ربط وتشفير سطر `realm` وتجهيز حساب الأدمن `[PM]` وشارة `[PM]`:**
   - يشفّر بيانات `Realm` بـ `AES-128` ويحدّث جدول `realm` بالآي بي المختار بدون مسح حسابات اللاعبين.
   - ينشئ حسابك الإداري (افتراضيًا `ahmedzahran` برتبة `AuthorityId = 8`)، ويعرض تركيب شارة `[PM]` لو عندك شخصية متكريتة.
6. **`[6/6]` الفحص النهائي الشامل للجاهزية (`Pre-Flight Verification`):**
   - يراجع كل الربط بين السورس والداتا بيز والكلينت ويطبع ملخص الجاهزية الكامل.

---

## 2) `2-Start-MoonQueen-Server.bat` — الاسكريبت المنفصل لتشغيل السيرفر
- **لو السيرفر متوقف:** يشغّل السيرفرات الثلاثة بالترتيب الصحيح وبانتظار فتح البورتات تلقائيًا:
  1. `MoonQueen.Login.exe` (بورت اللاعبين `9958` + بورت الربط `9865`)
  2. `MoonQueen.Game.exe` (بورت اللاعبين `5816` + بورت الوحوش `9866`)
  3. `MoonQueen.Ai.exe` (سيرفر الوحوش والـ Spawns)
  4. `لوحة تحكم السيرفر` (`http://127.0.0.1:8099`)
- **لو السيرفر شغال بالفعل وضغطت عليه:** يعرضلك حالة الخدمات ويديك خيار سريع لـ **إعادة التشغيل الآمن (`Restart`)** أو **الإيقاف الآمن بالترتيب العكسي (`Ai -> Game -> Login`)**.
