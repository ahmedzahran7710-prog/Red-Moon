# RedMoon على Windows

**لو سبق لك التثبيت والدخول للعبة: ابدأ بـ[الانتقال الآمن](MIGRATION.md)، وليس إنشاء قواعد جديدة.** هذا الدليل يخص الحزمة الكاملة ذات أسماء RedMoon الجديدة. ملفات التنقل/تصحيح الـlaunchers القديمة لا تُطبَّق عليها.

## التشغيل الجاهز مقابل التجميع

- `RedMoon-Windows-x64.zip` من إصدار خاص معتمد: سورس العمل + تشغيل ذاتي الاحتواء + داتا مرجعية وبذور نظيفة. لا يحتاج SDK أو Python للتشغيل. لا يتضمن العميل أو اللودر أو أسرارك.
- ملفات **Source code** التلقائية و`Code → Download ZIP`: كود فقط. للتجميع تحتاج SDK **10.0.403** وPython **3.9+** وإنترنت لاستعادة الحزم والأصول المثبتة، ثم `Build-RedMoon.cmd` في checkout جديد غير مثبت.
- الـsolution الوحيدة للعمل: `src/RedMoon.sln`. المشاريع في `src/RedMoon.*`. فتح الحل لا يشغّل اللعبة أو الاختبارات.
- `bundle-manifest.json` يحدد commit المصدر وبصمات الملفات، والتقرير بجانب ZIP يحدد بصمتها وحجمها. الحزمة المطابقة للتحقق فقط هي التسليم؛ راجع [VERIFICATION.md](VERIFICATION.md).

## التثبيت الجديد فقط

لا تنفذ هذه الخطوات فوق قاعدة قائمة، ولا تمسحها لتجاوز رفض Setup:

1. فك الحزمة المعتمدة في مجلد جديد مستقل عن العميل وأي تثبيت قديم.
2. شغّل MySQL من XAMPP. الإصدار الذي راجعناه هو MariaDB **10.4.32**. `Apache` ليس شرطًا للعبة.
3. شغّل Hamachi وتأكد أن عنوان جهازك هو المحدد في البروفايل؛ Start يتوقف إذا لم يكن العنوان نشطًا.
4. راجع `setup/owner-profile.json` قبل **أول Setup**. DB والربط الداخلي يظلان loopback، واسم السيرفر `RedMoon` والعميل5517.
5. افتح `Setup-RedMoon.cmd`. يدخل password الـroot في نافذة آمنة محلية ولا يُحفظ؛ **لا ترسله في المحادثة**.
6. اختر حساب لعبة عاديًا (3–16 حرفًا إنجليزيًا/رقمًا/underscore)، وكلمة سر لعبة مختلفة (8–16 حرفًا إنجليزيًا أو رقمًا). لا GM أو VIP أو CPs تلقائية.
7. انتظر `SETUP_OK`، ثم `Start-RedMoon.cmd` وانتظر `SERVERS_READY`.

الإعداد الافتراضي ينشئ `redmoon_account` و`redmoon_game` ومستخدم التشغيل المحدود `redmoon_runtime`. إذا كانت أي منها موجودة، يرفض الإعداد الاستبدال أو الـDROP. لا تستورد ملفات upstream ذات الحسابات/الشخصيات القديمة. ملفات `database` في الحزمة لتثبيت جديد فقط، وليست طريقة لتحديث السورس.

لو `mysql.exe` غير موجود في PATH أو أماكن XAMPP/MariaDB المعتادة:

```powershell
.\setup\Setup-RedMoon.ps1 -MysqlExe 'C:\xampp\mysql\bin\mysql.exe'
```

استخدم مسارك الحقيقي. HeidiSQL ليس executable الـCLI المطلوب. الفشل الجزئي يحتاج مراجعة؛ لا تُعاد التهيئة عشوائيًا.

## الأسرار والتشغيل اليومي

- أسرار التشغيل المولدة في `.local/runtime-secrets.dpapi`، مرتبطة بالكمبيوتر وحساب Windows الذي قام بالإعداد.
- `server/RedMoon.AccountServer.ini` و`server/RedMoon.GameServer.ini` يشيران لمتغيرات بيئة. Start يفتح الخزنة ويمررها للعمليتين.
- **Start يشغّل السيرفرين الحقيقيين**، وليس وضع محاكاة. العملية الثالثة `RedMoon.Admin` أداة إعداد/فحص محدد، وليست خادمًا تشغله يدويًا.
- لا تفتح EXE/F5 مباشرة ولا تشغّل نسختين على نفس القواعد/المنافذ. لا build فوق مجلد مثبت.
- استخدم `Stop-RedMoon.cmd` قبل إغلاق MySQL. يتأكد من PID والمسار ووقت البدء ويطلب حفظًا وإيقافًا منظمًا؛ لا force-kill لعملية مجهولة.
- `.local/logs` للـstdout/stderr و`server/Logs` لسجلات التطبيق. أرسل فقط الخطأ المطلوب بعد تنقيحه، وليس مجلدات logs أو vault أو داتا اللاعبين.

CMD تستخدم Windows PowerShell5.1 بالنظام و`ExecutionPolicy Bypass` للعملية الحالية فقط، دون تغيير سياسة الجهاز أو إضافة exclusions أو تعطيل Defender. لا تعطل الحماية إذا منعت ملفًا؛ راجع المصدر والبصمة ورسالة المنع.

## العميل الناجح يفضل كما هو

لو اللودر والعميل اشتغلا عندك، **لا تكرر إعدادهما** لمجرد الانتقال. الاسم والمنافذ والعنوان في البروفايل النشط تُحفظ.

للتثبيت الجديد فقط: أداة `Install-ClientConfig.cmd` تعمل مع ConquerLoader الرسمي وصيغة `config.json` التي راجعناها، وعميل5517. تتوقف عند ملف lock أو عدم توافق metadata بدل التخمين. metadata ليست شهادة أمنية للـbinary.

- لا تعِد تسمية MoonQueenLoader إلى ConquerLoader لتجاوز الفحص.
- لا تغيّر `version.dat` أو `Conquer.exe` أو تعطّل الحماية.
- لا تشغّل AutoPatch لتحديث العميل إلى باتش مختلف.
- للتوليد دون تعديل ملفات العميل: `.\setup\Install-ClientConfig.ps1 -GenerateOnly`.

## المنافذ والـfirewall

- دخول اللاعبين:9958، اللعبة:5816 على عنوان Hamachi المحدد.
- ربط AccountServer وGameServer:9865 على `127.0.0.1` فقط.
- DB:3306 على `127.0.0.1` فقط. **لا تفتح3306 أو9865 للاعبين.**

لا تُفتح firewall تلقائيًا. للأصدقاء المحددين فقط توجد `setup/Allow-Hamachi.ps1` مع عناوينهم الصريحة وبصلاحية مناسبة، و`-WhatIf` للمراجعة أولًا. بعد نقل EXEs إلى مسار جديد قد تحتاج مراجعة القواعد القديمة المقيدة بالمسار؛ الانتقال لا يغيرها خلسة ولا يعيد كتابة قاعدة قائمة.

## حدود النجاح

`SERVERS_READY` يثبت بدء وربط السيرفرين، لا دخول العميل أو صحة كل القتال والحفظ والاقتصاد. التحقق المعزول لا يثبت سعة لاعبين أو ثباتًا طويل المدة أو اكتمال Fan/Tower/Steeds/Arena/Arsenal/VIP. نعمل على هذه الأنظمة لاحقًا حسب الأولوية المتفق عليها؛ لا تغيير gameplay ضمن إعادة التنظيم.
