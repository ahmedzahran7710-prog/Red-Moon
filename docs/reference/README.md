# مراجع وأصل التسمية

- `REDMOON-RENAMES.json`: سجل النقل الفعلي بالتتابع؛ يُطبَّق انتقال المجلد ثم انتقال الملف أو المجلد الداخلي. يستخدمه فحص عدم فقد ملفات C#.
- `UPSTREAM-README.md` و`UPSTREAM-TODO.md`: وثيقتان تاريخيتان محفوظتان بنصهما. تعليمات .NET القديم/OpenSSL/المسارات فيهما **ليست تعليمات تشغيل RedMoon الحالية**.
- حقوق المصدر الأصلي في `licenses/FoxConquer5517-MIT.txt`، والترويسات الأصلية باقية داخل C#.
- `IniParser` وتعريفات `CO2_CORE_DLL` وأسماء NuGet تحتفظ بهويتها اللازمة. ملفات بيانات الخرائط وأرقام الباكتات وأسماء أعمدة SQL ليست branding يمكن استبداله بلا كسر توافق العميل/الداتا.

الأصل غير المعدّل بالكامل داخل `vendor/FoxConquer5517` في مستودع GitHub، وmanifest في `audit/fox5517-manifest.json`. لا تنسخ الأصل كنسخة عمل ثانية فوق `src/RedMoon.*`، ولا تنسب كود الطرف الثالث إلى مؤلف جديد لمجرد إعادة تسمية مشروعه.
