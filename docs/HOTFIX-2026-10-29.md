# تصحيح خطأ المسار عند فتح ملفات التشغيل — 2026-10-29

## ما الذي حدث؟

المستخدم فك حزمة Windows في المكان الصحيح، ثم ظهر:

```text
Split-Path : Cannot bind argument to parameter 'Path' because it is an empty string.
Setup-RedMoon.ps1:3
[string]$Root = (Split-Path -Parent $PSScriptRoot)
```

الخطأ داخل القيمة الافتراضية للـparameter، **قبل جسم الإعداد**: لا اتصال DB أو استيراد SQL من هذه المحاولة. الاختبار السابق كان يمرر `-Root` و`-ProfilePath` صراحة؛ نجاحه لم يغطِّ طريقة الدبل كليك بلا معاملات.

## الإصلاح المحدود

- ستة scripts تستخدم defaults فارغة، وتستنتج المسار بعد parameter binding من ملف السكربت الفعلي، لا من مجلد النافذة الحالي.
- يحتفظ `-Root` و`-ProfilePath` الصريحان بقيمتهما، ولا يُفرض مسار خاص بالمالك داخل الكود.
- خمسة CMD تمرر المسارات صراحة، وتختار Windows PowerShell النظامية، وتراعي المسافات والرموز والشرطة الخلفية النهائية، وتنقل exit code بدل إخفاء الفشل.
- الحد الأدنى معلن: Windows PowerShell5.1. لا تغيير لسياسة التنفيذ العامة أو antivirus؛ تظل السياسة الحالية للـprocess فقط كما كانت.
- **لا تعديل لكود اللعبة أوCommon.ps1 أوowner-profile.json أوSQL أوبيانات/.local أوexecutables.**

## لو الحزمة موجودة عندك بالفعل

استخدم `RedMoon-Launcher-Fix.zip` من تسليم هذه الجولة، بدل تنزيل السيرفر كله:

1. اقفل نافذة الخطأ، ولا تحذف أي قاعدة أو ملفات قديمة.
2. فك محتويات التصحيح مباشرة فوق `F:\AhmedZahran\RedMoon\RedMoon-Sorce`.
3. وافق على استبدال ملفاتCMD وملفاتPS1 الستة فقط؛ **ادمج الملفات داخلsetup الموجودة، لا تستبدل المجلد كله بمجلد فارغ**.
4. افتح `Setup-RedMoon.cmd` مرة أخرى. كلمة مرورDB تدخل محليًا فقط.
5. لو ظهر خطأ آخر، توقف عنده وأرسل نصه/صورته بعد إخفاء الأسرار؛ لا تعد الاستيراد يدويًا.

إذا سبق أن عدّلت سكربتات التشغيل بنفسك، احتفظ بنسخة منها أولًا. يحتوي التصحيح manifest بـSHA256 للملفات الأحد عشر، ولا يحتويconfigs أوvault أوSQL أوDLLs.

## التحقق — النتيجة لا تُفترض قبلCI

- محليًا: فحوصPython لحدود حزمة التصحيح، مطابقة البايتات، عدم تضمين الإعدادات/الداتا، قابلية إعادة إنتاج ZIP، والـdefaults/وسيطCMD؛ مع فحوصbaseline/clean-seed السابقة.
- اختبارWindows جديد: تشغيل native `powershell.exe -File` و`cmd.exe /c`، بدونRoot افتراضيًا ثم بمعاملاتصريحة، منمجلدآخر ومساربه spaces و`[]` و`&` و`!`؛ تحقق من exit0/exit7.
- تُعزل اختبارات المسار عند أول import باستخدامtest double، كي لا تتصلDB أو تفتحfirewall. كذلك يُشغَّلStart/Stop الحقيقيان علىfixture بلاinstallation للتأكد منرسائل الحماية الآمنة.
- fixture صغيرة بالنمط القديم تسجل هل أُعيد إنتاج نفس خطأbinding علىrunner؛ لا تُخلط صورة المستخدم مع إعادة إنتاج مستقلة.
- النسخة الكاملة تُعاد عليها اختبارات المكونات والإعداد والتشغيل المعزول، وحزمة جديدة ستضم التصحيح. تبقى الحاجة لتجربة العميل علىجهازالمالك، ولا يُدّعى حل كلGameplay/TODO.
